# Создание тестового аудиофайла

## Быстрый способ создать point_1.mp3:

### Вариант 1: ElevenLabs (рекомендуется)
1. Откройте: https://elevenlabs.io/
2. Введите текст:
   "Добро пожаловать в שער האשפות! Это туристическое место в Израиле. Здесь вы можете узнать больше об истории этого места. Спасибо за внимание!"
3. Выберите голос (например, Rachel)
4. Скачайте MP3
5. Переименуйте в: point_1.mp3
6. Поместите в папку: assets/audio/

### Вариант 2: Google Translate
1. Откройте: https://translate.google.com/
2. Введите: "Добро пожаловать в שער האשפות"
3. Нажмите кнопку "Слушать"
4. Запишите звук через браузер
5. Сохраните как: point_1.mp3

### Вариант 3: Онлайн запись
1. Откройте: https://online-voice-recorder.com/
2. Нажмите "Запись"
3. Прочитайте текст вслух
4. Скачайте MP3
5. Переименуйте в: point_1.mp3

## После создания файла:
1. Поместите point_1.mp3 в assets/audio/
2. Запустите: node scripts/add-audio-to-mapping.js
3. Проверьте в приложении: npm start

## Требования к файлу:
- Формат: MP3
- Имя: point_1.mp3
- Размер: до 10 МБ
- Длительность: 1-3 минуты
