## 🚀 **Создайте первый аудиофайл за 5 минут / Create Your First Audio File in 5 Minutes**

### **Шаг 1: Создайте аудио / Step 1: Create Audio**

**Вариант A: ElevenLabs (лучшее качество)**
1. Откройте: https://elevenlabs.io/
2. Введите текст: "Добро пожаловать в שער האשפות! Это туристическое место в Израиле."
3. Скачайте MP3
4. Переименуйте в `point_1.mp3`

**Вариант B: Google Translate (бесплатно)**
1. Откройте: https://translate.google.com/
2. Введите: "Добро пожаловать в שער האשפות"
3. Нажмите кнопку "Слушать"
4. Запишите звук
5. Сохраните как `point_1.mp3`

### **Шаг 2: Добавьте в проект / Step 2: Add to Project**

1. Поместите `point_1.mp3` в папку `assets/audio/`
2. Запустите: `node scripts/add-audio-to-mapping.js`
3. Проверьте: `npm start`

---

## ✅ **Готово! / Done!**

Теперь у вас есть работающий аудиогид! Теперь можно создавать аудио для остальных точек.

---

## 🛠️ **Полезные команды / Useful Commands**

```bash
# Добавить конкретный аудиофайл
node scripts/add-audio-to-mapping.js point_1.mp3

# Добавить все аудиофайлы в папке
node scripts/add-audio-to-mapping.js

# Создать тексты для аудиогидов
node scripts/create-audio-guide.js

# Очистить кэш и перезапустить
npx expo start --clear
```

---

## 🆘 **Если что-то не работает / Troubleshooting**

1. **Ошибка "Unable to resolve"**: Запустите `npx expo start --clear`
2. **Аудио не воспроизводится**: Проверьте, что файл добавлен в маппинг
3. **Нет звука**: Проверьте громкость устройства
