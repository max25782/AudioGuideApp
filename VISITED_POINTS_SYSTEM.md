# Система отслеживания посещений пользователя

## Обзор
Реализована полная система для сохранения ID пользователя и отслеживания посещенных им точек с постоянным хранением данных.

## ✨ Основные возможности

### 🆔 Управление пользователем
- **Автоматическая генерация уникального ID** при первом запуске
- **Постоянное хранение** в AsyncStorage
- **Автоматическая инициализация** при каждом запуске приложения

### 📍 Отслеживание посещений
- **Автоматическая отметка** при приближении к точке (радиус 150м)
- **Ручная отметка** при воспроизведении аудио
- **Предотвращение дублирования** посещений
- **Сохранение дополнительной информации**:
  - Время посещения
  - Координаты
  - Был ли воспроизведен аудиогид

### 🎨 Визуальные индикаторы
- **В списке точек**:
  - ✅ Зеленый бейдж с галочкой
  - 🎯 Дата посещения
  - 💙 Голубой фон для посещенных точек
- **На карте**:
  - 🟢 Зеленые маркеры для посещенных точек
  - ✓ Префикс в названии
  - 📊 Информация о посещении в описании

### 🔍 Фильтрация
- **Кнопка "Посещенные"** - показывает только посещенные точки
- **Счетчик посещений** в реальном времени
- **Интеграция с категориями** - все фильтры учитывают статус посещения

## 🛠 Техническая реализация

### Новые сервисы
```typescript
// UserService - управление пользователем и посещениями
- generateUserId() - создание уникального ID
- markPointAsVisited() - отметка посещения
- isPointVisited() - проверка посещения
- getVisitedPoints() - получение всех посещений
- getUserStats() - статистика пользователя
```

### Обновленные компоненты
```typescript
// PreprocessedDataService
- enrichPointsWithVisitStatus() - добавление статуса посещения
- getVisitedPoints() - фильтр посещенных точек
- getVisitStatsByCategory() - статистика по категориям

// LocationService  
- checkForVisits() - автоматическая проверка посещений
- setVisitTrackingRadius() - настройка радиуса отслеживания

// UI компоненты
- PointsList - визуальные индикаторы посещений
- MapView - разные маркеры для посещенных точек
- HomeScreen - кнопка фильтра посещенных точек
```

## 🔄 Workflow пользователя

1. **Запуск приложения**
   - Автоматическое создание/загрузка пользователя
   - Загрузка истории посещений
   - Обогащение точек статусом посещения

2. **Исследование точек**
   - Автоматическое отслеживание при приближении
   - Ручная отметка при воспроизведении аудио
   - Визуальная индикация посещенных точек

3. **Просмотр истории**
   - Фильтр "Посещенные" для просмотра истории
   - Карта с выделенными посещенными точками
   - Статистика посещений

## 💾 Хранение данных
- **AsyncStorage** для постоянного хранения
- **Ключи хранения**:
  - `@AudioGuide:user` - данные пользователя
  - `@AudioGuide:settings` - настройки приложения
- **Автоматическое восстановление** после перезапуска

## 🎯 Настройки отслеживания
- **Радиус автоотметки**: 150 метров (настраивается)
- **Интервал проверки**: каждые 5 секунд при движении
- **Кэш проверок**: очистка каждый час для повторных посещений

## 🔐 Приватность
- **Локальное хранение** - все данные остаются на устройстве
- **Анонимный ID** - без личной информации
- **Возможность очистки** данных в любой момент

Система полностью готова к использованию и автоматически сохраняет историю посещений пользователя!
