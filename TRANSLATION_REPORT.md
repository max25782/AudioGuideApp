# Отчет о переводе всех точек приложения

## Проблема
Из 5,684 точек интереса в приложении только 20 точек (0.4%) имели переводы на русский и английский языки. Остальные 5,664 точки (99.6%) отображались только на иврите, что делало приложение неудобным для пользователей, не владеющих ивритом.

## Решение
Создана система автоматического перевода с использованием словаря наиболее распространенных слов и фраз в израильской топонимике.

### Созданные инструменты:
1. **`scripts/translate-with-dictionary.js`** - основной скрипт для перевода
2. **`scripts/check-translations.js`** - скрипт для проверки качества переводов
3. **Словарь переводов** - 150+ наиболее распространенных слов

### Возможности словаря:
- Горы и холмы (הר, גבעה, תל, רכס)
- Водные объекты (עין, נחל, ים, כנרת)
- Города и поселения (קריה, עיר, כפר, קיבוץ)
- Направления (צפון, דרום, מזרח, מערב)
- Религиозные места (שער, מקדש, בית, קבר)
- Природные объекты (יער, שדה, עמק, מדבר)
- Библейские и исторические имена
- Современные объекты

### Принцип работы:
1. Поиск точного совпадения в словаре
2. Поиск частичного совпадения для составных слов
3. Транслитерация для неизвестных слов
4. Безопасность: резервное копирование данных
